## 📲 Installation & Troubleshooting Guide

If you encounter **"App not installed"** or **"Problem parsing the package"**, follow these 3 steps:

### 1. ⚠️ Clean Uninstall Previous Version (Crucial)
Android OS strictly prohibits overwriting an app if the cryptographic signature or debug certificate differs from the previous build on your device:
- Long-press the existing **jFindMe / jButterfly** app icon on your device home screen and tap **Uninstall**.
- *(Or via ADB: `adb uninstall com.jdroidx.jfindme`)*

### 2. 🛡️ Allow Unknown Apps Permission
- Open **Settings** → **Apps & Notifications** → **Special app access** → **Install unknown apps**.
- Select your browser (Chrome/Brave) or File Manager and enable **"Allow from this source"**.

### 3. 🚀 Install the New APK
- Tap the **Direct Download Link** above (ensure file size is ~100.4 MB, not 134 bytes).
